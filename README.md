# Quick Denomination

Quick Denomination is a free and open source app made to make cashiers' lives easier.

## Local Setup

1. Clone repository

   ```bash
   git clone https://github.com/jpdoshi/quick-denomination.git
   ```

1. Install dependencies

   ```bash
   cd quick-denomination
   npm install
   ```

2. Start the app

   ```bash
   npm start
   ```
