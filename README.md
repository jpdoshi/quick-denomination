# Quick Denomination

Quick Denomination is a free and open source app made to make cashiers' lives easier.

## Features

- **Fast and responsive**
- **Modern clean UI**
- **Denomination breakdown and total calculation**
- **Split denomination breakdown**
- **Multiple currencies support**
- **Web and mobile app support**
- **No ads**

## Local Setup

1. Clone repository

   ```bash
   git clone https://github.com/jpdoshi/quick-denomination.git
   ```

1. Install dependencies

   ```bash
   cd quick-denomination
   npm install
   ```

2. Start the app

   ```bash
   npm start
   ```
